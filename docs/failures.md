# Failure demonstrations

Generated by `uv run python scripts/failure_demos.py --docker`
at commit `f8a2f20` (clean tree).
Every command below was run, and its exit code checked against the expected one, in a
temporary clone of the repository; `<tmp>` stands for that directory. Commands run
through the project's entry point (`forecastgate.cli:main`, which `uv run forecastgate`
invokes).

Exit codes: 0 success; 3 data contract; 4 prediction contract; 5 publication
refused; 6 publication lock held; 7 gate not frozen; 8 gate config mismatch; 9
registry (no or stale champion); 10 gate rejected the candidate; 11 serving refused.

These demonstrations are local runs. GitHub Actions CI status, with links to runs,
is recorded in the README.

## 2. Leakage is detected, including two deliberately planted leaks

Features built from data truncated at a point in time must equal features built from full data whose later records were altered; every training label must satisfy t + h <= T. `future_window` (a 4-week mean reading y[t+1]) is caught by truncation equivalence; `origin_filter` (labels filtered on the origin only) by label eligibility. In the backtest harness, recipes only receive panels truncated at the fold cutoff, so `origin_filter` cannot reach future labels there at all, while `future_window` still changes the metrics.

Tests: `tests/test_leakage.py`, `tests/test_features.py`

## 6. Serving refuses stale, future-dated and tampered artifacts

## 7. Git credentials reach no layer of the image

The image carries git metadata for the freeze check. A discarded build stage reads the context's .git and passes on only history and a fresh config. Fake credentials are planted in a clone's .git/config, then every decompressed layer is searched; the discarded stage is the positive control.

Tests: `Dockerfile`, `scripts/scan_image_layers.py`

```
$ git config --local http.extraheader "AUTHORIZATION: basic FAKE-LEAK-<random>-1"
[exit 0]
```

```
$ git remote add leaktest https://FAKE-LEAK-<random>-2@example.invalid/r.git
[exit 0]
```
