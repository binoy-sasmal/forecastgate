# Test fixture

`online_retail_II_fixture.zip` is a slice of the UCI *Online Retail II* dataset, used so
tests and `uv run forecastgate reproduce --fixture` run offline.

- Source: Chen, D. (2012). Online Retail II [Dataset]. UCI Machine Learning Repository.
  https://doi.org/10.24432/C5CG6D
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/
- Changes: rows restricted to 60 steadily selling products from 2010-10-01 to the end of
  the file (2011-12-09), plus fee and service rows from 2010-11-15 to 2010-12-19. The
  window keeps the sheet overlap, the zero-transaction week of 2010-12-27 and the partial
  final week, and fits the six backtest folds under the full-run settings. Both sheets and their
  overlapping rows are kept as in the original. Generated by `scripts/make_fixture.py`.
- Pin: SHA-256 `ea595f1000bd1fd3f33bc4fd6ef743b9759b9acc9227bcdbe90a381c469dea80`. The
  generator is deterministic in which rows it selects, but the `.xlsx` bytes are not
  reproducible (workbook metadata timestamps), so the committed file is the reference.
